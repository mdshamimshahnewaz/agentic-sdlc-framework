# Milestones

Milestones describe durable delivery outcomes, not implementation transcripts.

## Naming

Use `MNNN-short-name.md`, for example `M001-foundation.md`.

## Status

Use one status: `proposed`, `active`, `blocked`, `completed`, or `cancelled`.
Only one milestone should normally be active unless the project explicitly
supports parallel delivery tracks.

## Workflow

1. Copy `MILESTONE_TEMPLATE.md` to the next numbered filename.
2. Define measurable completion criteria.
3. Link supporting dated plans.
4. Keep status and evidence current.
5. Update `../GATEWAY.md` and `../MEMORY.md` when the active milestone changes.
